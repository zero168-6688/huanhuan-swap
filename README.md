# 換換 Swap — App 起始專案

這是 Flutter 跨平台 App 的第一版可執行 UI 起始專案，包含首頁分類及全台縣市篩選、示範物品卡片、物品詳情、刊登／訊息／會員頁面，以及會員方案展示。

## 已納入的產品規格
- 平台定位：資訊刊登與交換媒合，不介入實際交換。
- 面交、寄送、運費、地點及交換條件由雙方自行協議。
- 免費會員：最多 2 則有效刊登。
- VIP 1：最多 5 則有效刊登。
- VIP 2：最多 10 則有效刊登。
- 開放範圍：全台灣，涵蓋 22 個縣市；首頁可依縣市與物品分類篩選。
- 月繳與年繳；價格尚未決定。
- VIP 僅增加刊登額度及進階功能，不提供付費置頂或搜尋排名優先。
- 分類搜尋規則對所有會員一致。

## 執行方式
1. 安裝 Flutter SDK 與 Android Studio / Xcode。
2. 解壓縮專案。
3. 在專案資料夾執行 `flutter pub get`。
4. 執行 `flutter run`。

## 目前狀態與限制
這是前端 UI 原型，不是已完成的正式服務。物品資料目前是示範資料；登入、雲端資料庫、圖片上傳、即時聊天、交換邀請、檢舉、會員付款及訂閱狀態尚未串接。
`supabase/schema.sql` 是資料庫起始草案，正式使用前仍需補上 Row Level Security、伺服器端刊登額度檢查、圖片存取政策、檢舉處理及訂閱付款驗證。

## 下一階段建議
1. 建立 Supabase 專案並設定 Auth。
2. 實作 profiles / listings 與圖片上傳。
3. 以資料庫交易或 RPC 在伺服器端檢查有效刊登上限。
4. 加入交換邀請與私訊。
5. 加入檢舉、封鎖、管理後台及隱私／服務條款。
6. 最後才接入 Apple App Store / Google Play 訂閱。

## 刊登額度定義
「有效刊登」指 status = active 的物品。已完成、已封存或已下架的刊登不計入額度。額度必須由伺服器端依會員資料判定，不能只靠 App 畫面限制。
